AndroidModKit Roadmap

AndroidModKit is being developed in small, practical stages. Features will be added as they become stable and useful.

Version 0.1 - Foundation

- [ ] Create the initial CLI
- [ ] Add Android environment detection
- [ ] Add Termux detection
- [ ] Implement "amk doctor"
- [ ] Implement "amk info"
- [ ] Add basic error handling
- [ ] Add initial automated tests
- [ ] Document installation and usage

Version 0.2 - Modding Tools

- [ ] Add mod/project inspection
- [ ] Detect common mod file types
- [ ] Add basic project information
- [ ] Add backup and restore functionality
- [ ] Improve Android filesystem handling

Version 0.3 - Script Tools

- [ ] Add script inspection
- [ ] Add script validation
- [ ] Add initial CLEO tooling
- [ ] Add Android-specific scripting support
- [ ] Improve error reporting

Version 0.4 - Extensibility

- [ ] Design a lightweight plugin system
- [ ] Allow game-specific tooling
- [ ] Add configurable commands
- [ ] Improve developer documentation

Version 0.5 - Android Development Tools

- [ ] Add Android development environment checks
- [ ] Detect common SDK/NDK configurations
- [ ] Add project diagnostics
- [ ] Improve Termux development workflows

Future

- [ ] Android graphical interface
- [ ] Integrated script editor
- [ ] Advanced mod management
- [ ] More game-specific integrations
- [ ] Additional developer automation

Development Principles

AndroidModKit will prioritize:

- Lightweight tooling
- Android-first workflows
- Termux compatibility
- Clear error messages
- Modular architecture
- Open-source development
- Stability over unnecessary features

The roadmap is subject to change as the project develops and community feedback is received.
